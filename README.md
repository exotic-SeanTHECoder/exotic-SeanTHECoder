## 🎧 Latest: Sample Pack Organizer

### [sample-pack-organizer](https://github.com/exotic-SeanTHECoder/sample-pack-organizer)

CLI tool that scans messy sample folders and auto-sorts audio files (Kicks, Snares, 808s, Melodies…) by filename + metadata. Generates a clean index.

Perfect for producers drowning in sample packs. MIT licensed.
